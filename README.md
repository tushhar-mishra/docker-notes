# Docker: From Zero to Production

Personal study notes on Docker, from "what is a container" down to the Linux internals (namespaces, cgroups, overlayfs, iptables), up to production operations, security, debugging and the bridge to Kubernetes. Written for DevOps/SRE interview preparation and real production work.

**Start here → [INDEX.md](INDEX.md)**: the ordered reading list (62 topics, each with a difficulty level).

Every topic follows the same structure: What it is · Why it exists · Analogy · How it works inside · Commands / files · Hands-on lab · Where you'll use it · When it breaks · Quick recap + interview questions.

> **Note:** sample command outputs show the *shape* of real output. Version numbers, IDs, hashes and sizes are illustrative, and the labs haven't all been run end to end yet. Your own terminal is the source of truth. Targets Docker Engine 29.x (November 2026).
